01 Wordmark

your learning state, everywhere.

22 x 6 modules 4 unit module 1 module letter gap --ink on --navy

Rectangles only, every edge on the module grid, so the wordmark is exact at 24 px in a header and at 400 px on a title card. Never set it in a typeface, never outline it, never tint it. Clear space is two modules on every side.

02 Mark

mark 40 mark 32 icon 32 icon 16

Six vertices, six nodes, one open edge. The bottom node is yellow because a learner is never finished: there is always a review due. The favicon is the same shape solved for 16 px: the hexagon fills, the n is knocked out of it, and only the yellow node survives.
